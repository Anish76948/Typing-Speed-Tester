# Typing Speed Tester 🚀

A simple and interactive typing speed test application built using HTML, CSS, and JavaScript.

## 🔹 Features
- ⏱️ Timer-based typing test  
- ⚡ Words Per Minute (WPM) calculation  
- 🔢 Characters Per Minute (CPM)  
- 🎯 Accuracy tracking  
- 🎨 Clean and responsive user interface  

## 🔹 Tech Stack
- HTML  
- CSS  
- JavaScript  

## 🔹 About
This project was built by customizing and modifying open-source code while learning frontend development. It helped me understand DOM manipulation, event handling, and basic UI design.

## 🔹 How to Use
1. Open the website  
2. Start typing the given text  
3. Track your speed, accuracy, and performance
